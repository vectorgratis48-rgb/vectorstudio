# Vector Production Studio

Website GitHub Pages/Jekyll untuk katalog vector, free vector, premium, edukasi, dan layanan.

## Prinsip
- Natural first, SEO second.
- Premium dan Free Vector terpisah.
- Kategori: Ayat Al-Qur'an, Ornamen Islami, Logo, Swirl, Pattern, Floral, dan kategori baru.
- Setiap asset mempunyai ID unik.
- WhatsApp: 085692520888.
- Gambar produk tidak dipaksa crop pada mobile; preview mempertahankan rasio.
- Hero menggunakan foto asli yang diberikan pengguna (`HRO-00001`).

## Jalankan lokal
Install Ruby/Jekyll lalu jalankan `bundle exec jekyll serve`.

## Deploy
Push repository ke GitHub dan aktifkan GitHub Pages dari branch utama / workflow Pages.

## Catatan gambar awal
`reference-ornament-01.jpg`, `reference-pattern-01.jpg`, dan `reference-pattern-02.jpg` berasal dari gambar sementara yang dikirim. Karena terlihat memiliki watermark pihak lain, file tersebut jangan dipublikasikan sebagai produk jual sampai hak distribusinya jelas.
